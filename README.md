# 💰 AI Financial Expense Tracking System

An intelligent expense tracking web application that helps users manage, analyze, and optimize their financial spending using AI-driven insights and data visualization.

---
Live - https://next-expense-tracker-ai-black.vercel.app/
## 🚀 Features

- 📊 Expense Tracking  
  - Add, edit, and delete daily expenses  
  - Categorize expenses (Food, Travel, Bills, etc.)

- 🤖 AI-Based Categorization  
  - Automatically classifies transactions  
  - Reduces manual effort  

- 📈 Interactive Dashboard  
  - Visualize spending trends using charts  
  - Monthly & yearly summaries  

- 🔍 Advanced Filtering  
  - Filter by date, category, or amount  
  - Track spending patterns  

- 💡 Smart Insights  
  - Detect overspending habits  
  - Suggest budget improvements  

- 🔐 Authentication  
  - Secure login/signup system  

---

### Frontend
